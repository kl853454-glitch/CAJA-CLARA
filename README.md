
# Caja Clara

Sistema de gestión financiera para pequeños emprendimientos.

## Objetivo
Facilitar el control de ingresos, gastos y retiros personales para mejorar la administración del dinero.

## Funcionalidades
- Registro de ingresos.
- Registro de gastos.
- Registro de retiros personales.
- Panel de resumen financiero.
- Cálculo automático del saldo.
- Historial de movimientos.
- Reportes financieros y gráficos.

## Tecnologías
- Python
- Streamlit
- Pandas
- Plotly
- SQLite

## Ejecución
Instalar las dependencias:

pip install -r requirements.txt

Ejecutar el sistema:

streamlit run app.py

## Proyecto académico
Caja Clara es un prototipo MVP orientado a pequeños emprendimientos.
